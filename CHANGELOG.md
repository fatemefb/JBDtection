#### 1. ✨ feat(ui): add quick entry interface and enhance pattern matching logic
**Commit:** `b616b3f6c7ad997ef545d20623e719e43f044074`
**Author:** fatemefb
**Date:** 2026-10-06

**Changes:**
- Implement a new "Quick Entry" (ورود سریع) UI component in the JB template
- Allow rapid data input with syntax highlighting and category-based chips
- Expand `TAG_PATTERN` to support terminal channel letters
- Add support for space-separated numeric suffixes
- Prevent false positives from dates and Ingress Protection (IP) ratings
- Resolve identifier collisions where Junction Box (JB) patterns incorrectly intercept Motor Control (MC) identifiers
- Add support for attached terminal letters in both JB and MC identifier detection
- Add regression tests for complex tag patterns

**Files Modified:**
- apps/backend/frontend/templates/JB.html (+325 lines)
- apps/backend/jb_detection/config.py (pattern expansion)
- apps/backend/jb_detection/pattern_matcher.py (MC/JB collision fix)
- apps/backend/tests/test_pdf_extraction_regressions.py (+83 tests)
